# Calculate Tree Crown Ratio

Calculate Tree Crown Ratio

## Usage

``` r
silv_tree_crown_ratio(height, height_base_crown)
```

## Arguments

- height:

  Total tree height.

- height_base_crown:

  Height to the base of the live crown.

## Value

A numeric vector with the crown ratio.

## Examples

``` r
silv_tree_crown_ratio(height = 20, height_base_crown = 8)
#> [1] 0.6
```
