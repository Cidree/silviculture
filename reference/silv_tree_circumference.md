# Calculate Tree Circumference

Calculate Tree Circumference

## Usage

``` r
silv_tree_circumference(diameter, units = "cm")
```

## Arguments

- diameter:

  Numeric vector of diameters or diameter classes

- units:

  The units of the diameter (one of `mm`, `cm`, `dm`, or `m`).

## Value

A numeric vector with the circumference in the same units.

## Examples

``` r
silv_tree_circumference(20)
#> [1] 62.83185
```
